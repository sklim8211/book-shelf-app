# 책장 (Book Shelf) — v1

사진으로 여러 권을 한 번에 등록해서 표지 그리드로 정리하는 개인용 서재 앱. v1 범위는 촬영→인식 확인→서재 저장, 그리고 검색 4가지뿐이고, 나머지(읽음 상태, 위시리스트, 중복 감지, 메모)는 나중에 필요해지면 추가합니다.

## 지금 상태 (Phase 1)

지금 버전은 실제 AI 인식이나 데이터 저장 없이, **화면과 흐름이 실제로 동작하는지**만 확인하는 단계예요. "촬영" 화면에서 사진을 고르면 실제 인식 대신 미리 준비된 가짜 결과 몇 권이 뜨고, 앱을 새로고침하면 등록한 책은 사라집니다 (아직 브라우저 메모리에만 저장).

## 실행 방법

```bash
npm install
npm run dev
```

터미널에 뜨는 주소(보통 http://localhost:5173)를 브라우저로 열면 됩니다. 휴대폰으로 테스트하려면 `npm run dev -- --host` 로 실행하고, 같은 와이파이의 휴대폰 브라우저에서 컴퓨터의 IP 주소로 접속하면 카메라 촬영까지 실제로 테스트할 수 있어요.

```
src/

  data/        지금은 가짜 데이터. Phase 2에서 Supabase 호출로 교체
  types.ts     책 데이터 모양 정의
```
